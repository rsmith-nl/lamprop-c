usage: lamprop [-h] [-l | -H] [-e] [-m] [-f] [-L | -v] [--log=(debug|info|warn|error|crit)]
               [file ...]

Calculate the elastic properties of a fibrous composite laminate. See the manual (lamprop-manual.pdf)
for more in-depth information.

positional arguments:
  file                  one or more files to process

options:
  -h, --help            show this help message and exit
  -l, --latex           generate LaTeX output (the default is plain text)
  -H, --html            generate HTML output
  -e, --eng             output only the engineering properties
  -m, --mat             output only the ABD matrix and stiffness tensor
  -f, --fea             output only material data for FEA
  -L, --license         print the license
  -v, --version         show program's version number and exit
  --log                 logging level debug,info,(default) warn,error,crit
